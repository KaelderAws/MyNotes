# Google Docs Notes App

Легковесное веб-приложение для ведения заметок с прямой интеграцией в Google Docs.
Работает **на 100% на стороне клиента** (без собственного бэкенда).

## Возможности
- Авторизация через официальный Google Identity Services (OAuth 2.0).
- Автоматически создаёт и работает в отдельной папке `Заметки (Notes App)` на вашем Google Диске.
- Каждая заметка — это полноценный Google Документ.
- **Горячая клавиша `Ctrl + S`**: мгновенное сохранение в Google Docs вместо браузерного сохранения веб-страницы (работает во всех раскладках, включая русскую `Ctrl + Ы`).
- **Чек-листы с цветовым выделением**:
  - *Обычный текст* — без выделения
  - *Зелёный* — Выполнено
  - *Жёлтый* — Отложено
  - *Красный* — Отменено
  - В Google Документе форматирование сохраняется как стандартное фоновое цветовое выделение текста.
- **Собственное контекстное меню сайта**:
  - Заменяет браузерное контекстное меню по правому клику.
  - Быстрое управление статусами чек-листа (Выполнено, Отложено, Отменено, Снять выделение).
  - Добавление новых пунктов, копирование/вставка, сохранение `Ctrl + S`, открытие в Google Docs и удаление.
- Кнопка быстрого перехода «Открыть в Google Docs» прямо из заметки.
- Удаление заметок в корзину Google Диска.
